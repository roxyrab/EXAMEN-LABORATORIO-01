# EXAMEN-LABORATORIO-01
A partir del proyecto base, se implementaron dos aplicaciones de colisión creativas en C++ para Unreal Engine: un sistema de impacto físico por bloqueo (block) con reproducción de audio y partículas en la clase Pelota, y un sistema de solapamiento (overlap) para la teletransportación precisa de la pelota mediante la clase Atajo.
